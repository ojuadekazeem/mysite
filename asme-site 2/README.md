# Ojuade Kazeem — Landing Site

Single-page site (React + TypeScript + Vite + Tailwind + framer-motion + lucide-react).
Content sourced from the Fiverr profile of Ojuade Kazeem (funnel builder, landing page
designer, email marketing expert).

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build to /dist
```

## Structure
- `src/Index.tsx` — hero (video crossfade loop), navbar, email capture, social footer
- `src/components/AboutSection.tsx`
- `src/components/FeaturedVideoSection.tsx`
- `src/components/PhilosophySection.tsx` — Strategy x Conversion
- `src/components/ServicesSection.tsx` — Funnels / Landing Pages & Email
- `src/index.css` — Instrument Serif import + `.liquid-glass` component class
